# Nayemur Rahman Portfolio

A personal portfolio site for Nayemur Rahman (Data Scientist & ML Developer). It's plain HTML, CSS and JavaScript with no build step. **All the content lives in JSON files in `data/`**, so updating the site means editing those files rather than code.

## How to run

The page loads its content from JSON files. Browsers block that when you double-click `index.html`, so view the site through a small local server:

- **Easiest:** double-click `scripts/serve.bat`. It starts a server with Python or Node.js and opens http://localhost:8000.
- **VS Code:** install the "Live Server" extension, right-click `index.html`, then choose **Open with Live Server**.
- **Online:** GitHub Pages, Netlify and similar hosts work as-is with no setup.

## Updating your data

| File | What it controls |
|---|---|
| `data/profile.json` | Name, headline, photo, CV file, logo, hero intro, scrolling tools strip (`coreTools`), stats strip (`stats`), terminal card, contact details (email, phone, WhatsApp, GitHub, LinkedIn), footer |
| `data/projects.json` | Project cards and the filter categories. `"featured": true` makes a card wide |
| `data/skills.json` | Skill cards (`groups`: each key is a card, each list is its skills) and skill logos (`icons`) |
| `data/experience.json` | "Experience & Achievements" timeline |
| `data/about.json` | About-me paragraphs, education timeline, publications |
| `data/cv.json` | CV only: job title, professional summary, which projects to list, extra experience bullets |

### Examples

**Add a project.** Copy one block in `data/projects.json` → `items` and change it:

```json
{
  "category": "Machine Learning",
  "name": "My New Project",
  "featured": false,
  "demo": "https://my-demo.streamlit.app/",
  "repo": "https://github.com/Rahman-Nayemur64/my-new-project",
  "points": ["What it does.", "How it works."],
  "tags": ["Python", "Pandas"]
}
```

- `category` must match one of the names in `categories`. Add a new one there to get a new filter tab.
- The link fields are optional and work like this:
  - `demo` shows **Live demo** and **Code** links.
  - `repo` on its own shows **View on GitHub**.
  - `link: {"label": "...", "url": "..."}` adds any other link, such as a paper.
  - With none of them, the card links to the GitHub profile.

**Add a skill.** Add a name to a list under `groups` in `data/skills.json`. To add a card, add a new key with its own list. Groups with 7 or more skills get a wider card. For a logo, look the skill up on https://devicon.dev and add it to `icons`, for example `"Docker": "devicon-docker-plain"`. Skills without a logo show their initials.

**Update the CV.** The CV (`assets/cv/Nayemur-Rahman-CV.pdf`) is built automatically from the JSON data in an ATS-friendly layout: one column, standard headings and real text that applicant-tracking systems can read. After changing any data file, double-click `scripts/build-cv.bat` to rebuild it. This needs Python plus Microsoft Edge or Google Chrome. The summary, title and project list are set in `data/cv.json`, and the look is in `cv/cv.css`. Set `"cv": ""` in `data/profile.json` to hide every CV button.

**Change the profile photo.** Replace `assets/images/profile.jpg` with a new square photo of about 480×480, keeping the same name. A different file name needs `"photo"` updated in `data/profile.json`.

**Add an experience.** Add an object to `data/experience.json`. `"type"` sets the coloured label and can be `work`, `education`, `research` or `award`. `"highlight": true` makes the entry stand out with a filled purple logo.

**Bold text in About.** Wrap words in double asterisks, for example `"I'm a **CSE graduate**"`.

### JSON rules (common mistakes)

- Put text in "double quotes", not 'single quotes'.
- Put a comma between items, but not after the last one.
- If the page shows a red "Couldn't load the portfolio data" message, the error names the file with the mistake. Paste that file into https://jsonlint.com to find the exact spot.

## After publishing online

In the `<head>` of `index.html`, replace the 4 occurrences of `SITE_URL` with the site's real address, for example `https://username.github.io/portfolio`. Until then, LinkedIn and WhatsApp can't show the preview image (`assets/images/og-image.png`) when someone shares the link.

```
Nayemur-Rahman-Portfolio/
├── index.html                 Page layout with empty containers that get filled from data/
├── data/                      ← ALL CONTENT. Edit these to update the site
│   ├── profile.json
│   ├── projects.json
│   ├── skills.json
│   ├── experience.json
│   ├── about.json
│   └── cv.json                Settings used only by the CV
├── assets/
│   ├── cv/Nayemur-Rahman-CV.pdf        The CV, generated by scripts/build-cv.bat
│   └── images/
│       ├── profile.jpg                 Profile photo (square)
│       ├── favicon.svg                 Browser-tab icon

├── css/
│   ├── base.css               Colour/font variables, reset, page-wide rules
│   ├── components.css         Shared pieces: buttons, chips, tabs, section headings, cards
│   ├── cursor.css             Custom mouse cursor (arrow that becomes a pointing hand)
│   └── sections/              One stylesheet per page section
│       ├── nav.css  hero.css  projects.css  skills.css
│       └── experience.css  about.css  contact.css  footer.css
├── js/
│   ├── utils.js               Creates the `Portfolio` namespace + small helpers
│   ├── icons.js               Small line icons (arrow, mail, download, …) + GitHub/LinkedIn logos
│   ├── data-loader.js         Loads the JSON files (add new data files here)
│   ├── main.js                Loads data, then starts every component (loaded last)
│   └── components/            One file per feature
│       ├── hero.js            Intro, social buttons, terminal card (types itself out), stats strip, tools marquee
│       ├── profile.js         Profile photo, name card, all "Download CV" links
│       ├── reveal.js          Fade-in of sections while scrolling
│       ├── projects.js        Project filter tabs + cards
│       ├── project-art.js     Generated artwork at the top of each project card (no screenshots needed)
│       ├── skills.js          Skill group cards
│       ├── experience.js      Experience timeline
│       ├── about.js           Bio, education, publications
│       ├── contact-info.js    Contact rows + footer links
│       ├── contact-form.js    Builds Gmail / WhatsApp / mailto links from the form
│       ├── copy-buttons.js    "Copy" buttons for email/phone
│       ├── nav.js             Mobile menu, active-link highlighting, scroll progress bar
│       ├── glow-cards.js      Card highlight that follows the mouse
│       ├── starfield.js       Animated star + icosahedron background
│       └── cursor.js          Custom mouse cursor (mouse/pen only; touch screens keep the normal one)
├── cv/
│   ├── cv.css                 CV layout (A4, one column, ATS-friendly)
│   └── cv.html                Generated CV page (don't edit; rebuild instead)
└── scripts/
    ├── serve.bat              Starts a local server for previewing
    ├── build-cv.bat           Rebuilds the CV PDF from data/ (double-click)
    └── build-cv.py            The CV builder that build-cv.bat runs
```

## Notes

- Section headings and their short descriptions ("Featured Projects", "Let's build something together", …) are part of the page design and live in `index.html`.
- Colours and fonts are the `:root` variables in `css/base.css`.
- The contact form has no server behind it. Clicking Send shows pre-filled Gmail, WhatsApp and mail-app links.
